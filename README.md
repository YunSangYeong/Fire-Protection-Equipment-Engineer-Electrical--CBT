## 기능

대시보드, 실전 모의시험, 과목별 랜덤 학습, 오답 재학습, 북마크, 통계, JSON/CSV 문제 가져오기·중복 제거·검증 대기·근거 입력 후 로컬 승인·검색·페이지 목록·내보내기를 제공합니다. 가져온 문제는 공용 저장소에 자동 게시되지 않습니다.

실전은 절대 종료시각 저장, 답안 수정·자동 저장, 만료 자동 제출, 중복 제출 방지, 제출 후 해설과 과목별 결과·과락 표시를 제공합니다. 랜덤은 즉시 채점과 순회 중 중복 방지를 제공합니다. 두 모드 모두 응답 후 Space로 다음 문제에 이동하고, 마지막 실전 문제에서 Space로 자동 제출하지 않습니다. 미응답·길게 누르기·수정키·입력 요소·메뉴·대화상자를 보호하는 기준 로직을 유지했습니다.

학습 기준/연도 선택 메뉴와 상단 상시 면책 배너는 없습니다. 비공식 표시는 사이드바·푸터, 규칙 확인 상태와 검수 한계는 문제은행 화면·문서·문항 출처에 있습니다. 실제 저장 실패·손상 경고는 유지합니다. 모바일 메뉴는 독립 세로 스크롤, 100vh/100dvh 제한, 자식 높이 보존, overscroll containment를 적용했습니다.

## 로컬 개발과 검증

Node.js `.node-version`: 24.19.0. 기존 체크아웃을 사용하며 별도 worktree는 필요하지 않습니다.

```bash
npm ci --cache /tmp/fire-npm-cache
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
npm run check
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

시스템 Chromium이 없으면 `npx playwright install --with-deps chromium` 후 `npm run test:e2e`를 사용합니다. CI는 이 경로로 브라우저를 설치합니다. 이 환경에서는 `/usr/bin/chromium`으로 검증했습니다. 새로운 CI 머신에서의 검증은 아직 수행하지 않았습니다.

최종 결과: 단위 18개 통과, Chromium PC/Pixel 7 에뮬레이션 브라우저 검사 27개 통과·1개 해당 없음으로 건너뜀, TypeScript 및 프로덕션 빌드 성공. 작은 세로 390×480, 가로 740×360, 메뉴 글자 확대에서 실제 휠과 CDP 터치 입력을 검증했습니다. 실기기·Safari·Firefox는 미실행입니다. [상세 검사](docs/validation.md).

저장은 자격증 고유 localStorage 키를 사용합니다. 최근 응답 5,000개·시험 30회 보관. 브라우저·origin에 따라 기록이 분리되며 iframe/개인정보 보호 설정에 따라 저장이 제한될 수 있습니다. JSON 백업 내보내기는 제공하지만 기록 백업 UI 복원은 구현하지 않았습니다. 초기화는 확인을 받고 개인 데이터만 지우며 기본 은행을 유지합니다.

## 원격 반영과 배포 — 첫 사전 차단으로 중단

workflow [.github/workflows/pages.yml](.github/workflows/pages.yml)는 main push → validate(설치·단위·빌드·브라우저 검사) 성공 → Pages 업로드/deploy, PR은 검증만 수행하는 v1.4.0 기본 흐름입니다. deploy는 main 제한과 `needs: validate`, 최소 pages/id-token 권한을 사용합니다. 자동 재시도는 넣지 않았습니다.

**최초 사전 확인:** `https://api.github.com/repos/YunSangYeong/Fire-Protection-Equipment-Engineer-Electrical--CBT` 읽기 요청이 `curl: (56) CONNECT tunnel failed, response 403`, HTTP 응답코드 `000`으로 차단됐습니다. 이는 TLS 터널 단계 프록시 거부이며 GitHub가 응답한 API 403이나 권한 부족 판정은 아닙니다. 토큰 값을 요청·추출하거나 GitHub 인증을 대체하지 않았습니다.

요청에 따라 이 시점에서 배포를 중단했습니다. API 재조회·대체 경로·main push·수동 workflow 실행·재실행은 하지 않았습니다. 코드는 배포를 유발하지 않는 `codex/fire-cbt-standard` 브랜치에 보존합니다. PR은 생성하지 않았습니다. 대상 main은 최초 커밋 상태를 유지합니다. CI/Pages 실행을 시작하지 않았고 Pages 최초 설정·기존 공개 여부·공개 화면은 확인하지 못했습니다.
